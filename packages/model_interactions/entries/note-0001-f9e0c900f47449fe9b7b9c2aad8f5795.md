## Package created: model_interactions

This package records interactions with the Trail Power Model (Capella model, repo `Trail_Power_for_Campgrounds`, branch `master`): what was read or analyzed, what was changed, and why.

Created at Tony's request on 2026-10-20. Intended content:
- Observations from analyzing the model (health checks, unallocated functions, missing exchange items, etc.)
- Decisions about model changes, naming the elements changed and the resulting commit
- Lessons learned while modeling

Model changes themselves happen through capella-fabric; the reasons for them are logged here.
